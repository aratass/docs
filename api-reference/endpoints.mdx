The TEE server exposes a REST API. The SDK's `Wraith` and `WraithAgent` classes wrap these endpoints — most developers don't call them directly.

The TypeScript examples on this page build on each other. Run them in order, starting with the client in the Authentication section.

## Authentication

All requests require an API key:

```
Authorization: Bearer wraith_live_abc123
```

Optional BYOM headers:

```
X-AI-Provider: openai
X-AI-Key: sk-...
```

### Example Client

The examples share one `fetch` wrapper. It sends the API key as a bearer token, adds the BYOM headers when you pass a model key, and turns error responses into a `WraithApiError`:

```typescript
const WRAITH_API_URL = "https://api.wraith.dev";

type HttpMethod = "GET" | "POST" | "DELETE";

interface WraithClientOptions {
  apiKey: string;
  baseUrl?: string;
  // Optional BYOM: run agent chat on your own model provider key.
  ai?: { provider: "gemini" | "openai" | "claude"; apiKey: string };
}

class WraithApiError extends Error {
  readonly statusCode: number;

  constructor(statusCode: number, message: string) {
    super(message);
    this.name = "WraithApiError";
    this.statusCode = statusCode;
  }
}

function createWraithClient(options: WraithClientOptions) {
  const baseUrl = (options.baseUrl ?? WRAITH_API_URL).replace(/\/+$/, "");
  const headers: Record<string, string> = {
    Authorization: `Bearer ${options.apiKey}`,
    "Content-Type": "application/json",
  };
  if (options.ai) {
    headers["X-AI-Provider"] = options.ai.provider;
    headers["X-AI-Key"] = options.ai.apiKey;
  }

  return async function request<T>(method: HttpMethod, path: string, body?: unknown): Promise<T> {
    const res = await fetch(`${baseUrl}${path}`, {
      method,
      headers,
      body: body === undefined ? undefined : JSON.stringify(body),
    });

    if (!res.ok) {
      // Error bodies use the ApiError shape from Error Responses below.
      const error = (await res.json().catch(() => null)) as Partial<ApiError> | null;
      throw new WraithApiError(res.status, error?.message ?? res.statusText);
    }

    return (await res.json()) as T;
  };
}

const apiKey = process.env.WRAITH_API_KEY;
if (!apiKey) {
  throw new Error("Set WRAITH_API_KEY to your Wraith API key");
}

const wraith = createWraithClient({ apiKey });
```

## Agent Endpoints

### Create Agent

```
POST /agent/create
```

Create a new agent with a `.wraith` name.

**Request:**

```typescript
interface CreateAgentRequest {
  name: string;          // "alice" (becomes alice.wraith)
  chain: string;         // "horizen" | "stellar" | "ethereum" | ...
  wallet: string;        // owner wallet address
  signature: string;     // EIP-191 or ed25519 signature
  message?: string;      // signed message (for verification)
}
```

**Response:** `AgentInfo`

```typescript
interface AgentInfo {
  id: string;            // UUID
  name: string;          // "alice"
  chain: string;         // "horizen"
  address: string;       // agent's on-chain address
  metaAddress: string;   // stealth meta-address
}
```

**Example:**

```typescript
import { Keypair } from "@stellar/stellar-sdk";
import { Chain } from "@wraith-protocol/sdk";

// The owner wallet signs a message to prove it owns the new agent.
// Keypair.random() keeps the example self-contained. Sign with the real owner wallet.
const owner = Keypair.random();
const ownershipMessage = "Sign to create Wraith agent";

const agent = await wraith<AgentInfo>("POST", "/agent/create", {
  name: "alice",
  chain: Chain.Stellar,
  wallet: owner.publicKey(),
  signature: owner.sign(Buffer.from(ownershipMessage)).toString("hex"),
  message: ownershipMessage,
} satisfies CreateAgentRequest);

console.log(`${agent.name}.wraith on ${agent.chain}: ${agent.metaAddress}`);
```

## Chat

### Send Message

```
POST /agent/:id/chat
```

Send a natural language message to the AI agent.

**Request:**

```typescript
interface ChatRequest {
  message: string;
  conversationId?: string;  // continue existing conversation
}
```

**Response:**

```typescript
interface ChatResponse {
  response: string;          // agent's text reply
  toolCalls?: ToolCall[];    // tools the agent executed
  conversationId: string;    // conversation ID for continuity
}
```

```typescript
interface ToolCall {
  name: string;              // "send_payment", "scan_payments", etc.
  status: string;            // "success" or "error"
  detail?: string;           // JSON string with tool result
}
```

**Example:**

```typescript
const reply = await wraith<ChatResponse>("POST", `/agent/${agent.id}/chat`, {
  message: "What is my balance?",
} satisfies ChatRequest);

// Pass conversationId to keep the next message in the same conversation.
const followUp = await wraith<ChatResponse>("POST", `/agent/${agent.id}/chat`, {
  message: "Scan for incoming stealth payments",
  conversationId: reply.conversationId,
} satisfies ChatRequest);

for (const call of followUp.toolCalls ?? []) {
  console.log(`${call.name}: ${call.status}`);
}
```

## Pagination

List endpoints such as `GET /agents`, `GET /agent/:id/conversations`, and `GET /agent/:id/notifications` return the whole collection in one response. They take no page or cursor parameters, so page through results on the client. This example loads messages only for the conversations on the first page:

```typescript
const PAGE_SIZE = 20;

function getPage<T>(items: readonly T[], pageIndex: number, pageSize = PAGE_SIZE): T[] {
  return items.slice(pageIndex * pageSize, (pageIndex + 1) * pageSize);
}

const conversations = await wraith<Conversation[]>("GET", `/agent/${agent.id}/conversations`);

for (const conversation of getPage(conversations, 0)) {
  const messages = await wraith<Message[]>(
    "GET",
    `/agent/${agent.id}/conversations/${conversation.id}/messages`,
  );
  console.log(`${conversation.title}: ${messages.length} messages`);
}
```

## Error Responses

All errors return JSON with a `message` field:

```typescript
interface ApiError {
  message: string;
  statusCode: number;
}
```

| Status Code | Meaning |
|---|---|
| 400 | Bad request (missing params, invalid signature) |
| 401 | Unauthorized (invalid API key) |
| 404 | Agent/invoice/conversation not found |
| 409 | Conflict (name already taken) |
| 500 | Server error |

### Example

```typescript
// 400 Bad Request
const invalidName: ApiError = {
  message: "Name must be 3-32 characters, lowercase alphanumeric and hyphens only",
  statusCode: 400,
};

// 401 Unauthorized
const invalidApiKey: ApiError = {
  message: "Invalid API key",
  statusCode: 401,
};

// 409 Conflict
const nameTaken: ApiError = {
  message: "Name 'alice' is already registered",
  statusCode: 409,
};
```

### Handling Errors

`WraithApiError` carries the HTTP status code, so branch on `statusCode`. A 404 from the name lookup means no agent is registered under that name:

```typescript
async function isNameAvailable(name: string): Promise<boolean> {
  try {
    await wraith<AgentInfo>("GET", `/agent/info/${encodeURIComponent(name)}`);
    return false; // an agent already uses this name
  } catch (err) {
    if (err instanceof WraithApiError && err.statusCode === 404) {
      return true;
    }
    throw err; // 401 invalid API key, 500 server error, ...
  }
}

console.log("alice available:", await isNameAvailable("alice"));
console.log("bob available:", await isNameAvailable("bob"));
```
